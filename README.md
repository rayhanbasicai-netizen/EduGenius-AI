**EduGenius AI**

EduGenius AI is an AI-powered learning platform for Bangladeshi students. It works in Bengali and English and uses Google AI Studio (Gemini) to explain topics, create quizzes, and answer questions.

Live Demo: YOUR_LIVE_URL

**Features**

- Home page with an interactive hero section
- AI Study Hub: enter a topic and get a clear explanation (Concept, Analogy, Example)
- Smart Quiz: AI-generated MCQs with instant feedback and explanations
- AI Chat Tutor: ask questions and get step-by-step help
- Settings: add your Gemini API key, choose a model, and set the temperature
- Responsive design for mobile and desktop

**Tech Stack**

- HTML, CSS, Tailwind CSS, JavaScript
- Google AI Studio (Gemini API)
- Hosted on Vercel / Netlify / GitHub Pages

**How to Run**

1. Get a free API key from https://aistudio.google.com/
2. Clone this repo:
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
3. Open index.html in your browser
4. Go to Settings, paste your API key, and click Save

Your API key is stored only in your browser (localStorage). Never upload it to GitHub.
